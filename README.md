# General Active Transportation Infrastructure Specification (GATIS)

Access version 1.0 of the specification on the [GATIS Explorer](https://dotbts.github.io/BPA/) where you can also review the [GATIS Playbook](https://docs.google.com/document/d/1_3Zz1hudUCunHNpgFDY74ybvNgjttcTdQ9c9LTYm3uE/edit?tab=t.0#heading=h.z6dk4uepjp68).

## Draft Specification Files

The [draft_gatis_specification/specification_jsons](https://github.com/dotbts/BPA/tree/main/draft_gatis_specification/specification_jsons) folder contains JSON files that describe the different types and allowed attributes for each GATIS feature type. The [draft_gatis_specification/templates](https://github.com/dotbts/BPA/tree/main/draft_gatis_specification/templates) folder contains GeoJSON files that reflect the recommended and required types and attributes for each feature type at each tier level plus one that includes all optional attributes. Lastly, the [draft_gatis_specification/sample_data](https://github.com/dotbts/BPA/tree/main/draft_gatis_specification/sample_data) contains Jupyter Notebooks showing example pipelines for converting existing municipal data into GATIS. The notebook also contains links to download the sample data.

# The National Collaboration on Bicycle, Pedestrian, and Accessibility Infrastructure Data (NC-BPAID)

BTS has retired the National Collaboration on Bicycle, Pedestrian, and Accessibility Infrastructure Data (NC-BPAID) and is in the process of standing up a new GATIS working group. Previously, NC-BPAID worked across sectors to develop a shared data specification for geospatial bicycle, pedestrian and accessibility infrastructure data across the United States, to enable data pooling and coordination at a national scale. This work resulted in the release of GATIS v1.0 and associated resources on the [GATIS Explorer](https://dotbts.github.io/BPA/).

## Background

Nationwide, there is a gap in data describing the infrastructure used by people walking, biking, and rolling. The location and attributes of the infrastructure that allows for safe and comfortable travel -- like sidewalks, bike lanes, and curb ramps -- is often unmapped. Where geospatial data does exist, it is often inaccurate, fragmented, and inconsistently defined in structure and content and frequently siloed from other datasets. This results in active transportation data that does not provide value within or across jurisdictional boundaries, limiting the ability of agencies, advocates, researchers, and members of the public to identify and close gaps in safety and connectivity for people walking, biking, and rolling.

The objective of the [Bureau of Transportation Statistics](https://www.bts.gov/) is to help fill these data gaps with nationwide geospatial data layers for the extent, connectivity, and condition of bicycle, pedestrian, and accessibility infrastructure in public rights of way and transportation terminals. Standardization of the data across jurisdictions is the first step to making the data available, easy to understand, and easy to use.

There are many organizations that have recognized and are working towards filling these data gaps across the government, academic, nonprofit, and private sectors. The grassroots effort to build GATIS represents a systematic and collaborative process to help the field progress towards widespread, interoperable geospatial data for active transportation infrastructure.
